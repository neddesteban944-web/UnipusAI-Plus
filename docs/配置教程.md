# 配置教程

从零开始，大约 3 分钟。

## 需要准备

- 能登录 U校园（`ucontent.unipus.cn`）的浏览器（Edge / Chrome）
- 一个大模型的 API Key（DeepSeek、Kimi、通义等，任选；也支持本地 Ollama）
- 程序本体：`UnipusAI.exe`

## 第一步：把请求复制出来

1. 浏览器登录 U校园，进入**任意一门课**的页面（比如读写教程）
2. 按 `F12` 打开开发者工具，切到 **网络 / Network** 面板
3. 点一下面板上的 **Fetch/XHR** 过滤按钮（这一步很关键，否则你看到的是一堆图片和 CSS）
4. 按 `F5` 刷新页面，让请求列表出现内容
5. 在任意一条 `ucontent.unipus.cn` 的请求上**右键** → **复制** → **以 cURL 格式复制（bash）**

> 只想复制 Cookie 也可以：右键请求 → 复制 → 复制请求头，然后找到 `Cookie:` 那一行整条复制。
> 注意 **Cookie 里必须包含 `jwt=`**，那才是登录凭证。

## 第二步：生成配置

在程序目录打开终端（在该文件夹地址栏输入 `cmd` 回车即可），执行：

```
UnipusAI.exe init
```

把刚才复制的内容粘贴进去（可以多行），然后按 `Ctrl+Z` 再回车结束输入。

程序会自动识别并写入：

| 字段 | 从哪里来 |
| --- | --- |
| `cookie` | 请求头 `Cookie` 整条（含 `jwt=`） |
| `open_id` | 从 `jwt` 里解出来的 `openId` |
| `authorization` | 请求头 `Authorization`（没有就不填，程序会用 cookie 里的 jwt） |
| `x_annotator_auth_token` | 请求头同名值；**抓不到时按前端算法自动生成**（默认就是这条路） |
| `class_id` / `curricula_id` | 页面 URL 里的 `cid=` 与 `cloudCurriculaId=` |
| `u_school` | 请求头 `u-school`（没有就不填） |
| `course_id` | 请求 URL 里的 `course-v2:...`（页面请求里通常没有，用下一步选） |

## 第三步：选择课程

```
UnipusAI.exe courses
```

会列出你账号下的课程：

```
我的课程（共 3 门）：
   1. 26级综合英语I / 新四级强化辅导 听力（新版）
      course_id=course-v2:1234567890abcdef+your_course_template+20230101
      class_id=1000000000000000001  curricula_id=999999
   2. ...
```

然后：

```
UnipusAI.exe use 1
```

`course_id` / `class_id` / `curricula_id` 会自动写入 `config.json`。

## 第四步：填写大模型

编辑 `config.json`，填三样：

```json
{
  "api_key": "sk-xxxxxxxx",
  "base_url": "https://api.deepseek.com",
  "model": "deepseek-flash"
}
```

`base_url` 只写主机名也可以，程序会自动补 `/v1`；不同厂商示例：

| 厂商 | base_url | model 示例 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-flash` |
| Kimi / Moonshot | `https://api.moonshot.cn/v1` | `kimi-k2-turbo-preview` |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` |

## 第五步：先验证，再开刷

```
UnipusAI.exe progress --names
```

能打印出课程单元/任务树就说明配置通了。之后按顺序：

```
UnipusAI.exe dump-text --names       # 导出题目（顺便缓存听力转写）
UnipusAI.exe test-types              # 每种题型抽一题试答，不提交
UnipusAI.exe debug <groupId>         # 单组预览，不提交
UnipusAI.exe run --interval 3000     # 全量答题（会真实提交）
```

想只做必修任务：`config.json` 里把 `learning_strategy` 改成
`learn_all_compulsory_course`（默认值），改成 `learn_all` 就是全部任务。

## Cookie 过期了怎么办

`jwt` 一般只有 1~2 天有效期，过期后程序会报 401 / `unAuthenticated`，或者
`courses` 列不出课程。重新执行一次：

```
UnipusAI.exe init
```

再粘贴一次新的 cURL 即可，其他字段会保留（`course_id` 不受影响）。

## 多个账号 / 多台设备

每个账号一份程序目录即可（配置跟着 `config.json` 走）。
也可以只准备一份程序，用复制/备份 `config.json` 的方式切换账号。
