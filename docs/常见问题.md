# 常见问题（FAQ）

## 1. 提示「安全包中没有可用的凭证」或 SSL 相关错误

这是系统 TLS（schannel）环境异常导致。本项目已显式改用 rustls，
请确认你运行的是本仓库编译的版本（上游 v3.3 发行版走系统 TLS，在部分环境会报此错）。

## 2. 报 401 / `unAuthenticated`，或 `courses` 列不出课程

通常是 cookie 过期。

- 执行 `UnipusAI.exe courses`，如果列不出课程，基本就是过期了
- 重新 `UnipusAI.exe init` 粘贴一次新的 cURL

## 3. `反序列化失败: invalid type: floating point 0.6, expected i32`

上游的老 bug：部分课程接口把分数返回成小数、把时间返回成 `null`。
本仓库已修复（宽松解析），请使用本仓库编译的版本。

## 4. 任务提交了但「没通过」

课程通常要求达到最低得分比例（常见 60%）。没到线时任务仍算未完成，重新 `run` 会重做它。
提升通过率的办法：

- 先用 `debug <groupId>` 看具体作答，判断是解析问题还是模型能力问题
- 换更强的大模型（改 `model`）
- 材料长的题目可以调大 `max_material_chars`（默认 16000）
- 听力题确保音频识别可用（见第 5、6 条）

## 5. 提示「未找到 ffmpeg」/ 听力题缺少材料

听力题若没有内嵌脚本/字幕，就需要本地转写，而转写依赖 ffmpeg：

- 把 ffmpeg 的 `bin` 目录加入系统 `PATH`，或
- 把 `ffmpeg.exe` 放到程序目录下的 `tools\ffmpeg\bin\`（启动器会自动加 PATH）

下载地址：<https://www.gyan.dev/ffmpeg/builds/>

## 6. Whisper 模型下载很慢或失败

模型首次使用会自动下载（`base` 约 280MB）。国内建议设置镜像：

```bat
set HF_ENDPOINT=https://hf-mirror.com
```

（`UnipusAI.cmd` 启动器已默认设置。）缓存默认在 `~/.cache/whisper-candle/`，
可用环境变量 `HF_HOME` 指定到别处。想要更准可以设 `"whisper_model": "small"`。

## 7. 中文微课转写出来是乱码英文

把 `config.json` 的 `whisper_language` 改成 `auto`（默认）或 `zh`。
本项目已让转写缓存按语种区分，改完会重新识别，不会复用旧语种的结果。

## 8. 提示「操作过于频繁」

服务端限频。程序会自动等待冷却（递增 180s，最多 5 次）后重试。
也可以把 `config.json` 的 `interval_ms`（两次提交间隔）调大，例如 5000。

## 9. 讨论题 / 单词卡 / 纯视频页面怎么处理

- **讨论题（discussion）**：自动生成英文发言并发布到课程讨论区，再标记完成
- **单词卡（vocabulary）**：无需作答，直接标记完成
- **纯视频、长文阅读等无题目页面**：自动发送「标记已看」

单独处理某个任务组：

```bash
UnipusAI.exe group <groupId>
```

## 10. 只想做必修 / 想全部做

编辑 `config.json`：

```json
"learning_strategy": "learn_all_compulsory_course"    // 只做必修（默认）
"learning_strategy": "learn_all"                     // 全部任务
```

## 11. 会不会被封号 / 有什么风险

本工具只是模拟你自己浏览器的请求，但仍属于自动化操作，可能触发风控或限频。
请自行评估风险并遵守学校与平台规定。**建议先用 `debug` 预览、小范围验证后再批量执行。**

## 12. 报错 `relative URL without a base`

部分课程的媒体地址是相对路径（`qs-prod/...`、`qs-gray/...`）。
本仓库已修复（自动补全 CDN 域名），请使用本仓库编译的版本。

## 13. 能不能在 macOS / Linux 上跑

代码本身是跨平台的，但目前只在 Windows 上验证过（音频转写、启动器都是 Windows 脚本）。
在别的系统上需要自行编译，并确保 `ffmpeg` 在 `PATH` 中。
